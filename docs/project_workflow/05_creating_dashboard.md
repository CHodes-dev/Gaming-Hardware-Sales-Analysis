# Creating Dashboard

## Introduction

Many people create dashboards using a wide array of charts, colors, and complex-looking elements—choices that actually make the result appear unprofessional. In contrast, recruiters look for data analysts who know how to build dashboards that provide actionable insights, enabling informed business decision-making.

To create a dashboard that features easy-to-understand visualizations and effectively communicates information, one can utilize the **DASH framework**.

## Creating Dashboard Framework

Using this framework makes creating a dashboard easier by providing a clearer direction.

**Decision**

This can be determined by answering the following questions:
- What actions can be taken after viewing this dashboard?
- Who is responsible for making those decisions?
- How frequently do these decisions need to be made?

**Audience**

This can be determined by answering the following questions:
- Who will be using this dashboard?
- What level of detail do they require?

**Signal**

This can be determined by answering the following question:
- What are the top 3–5 essential metrics to include?
Select the metrics that are most important to the audience; this helps them make sound decisions and highlights our business capabilities.

**Hierarchy**

This can be determined by answering the following question:
- What should the audience see first, second, and so on?

## Creating Dashboard Process

The dashboard will be built using Power BI, with the following plan:
- Decision: Inventory-related decisions based on product and region, assessed on a monthly basis.
- Audience: Product/Inventory Management team (non-technical; requires trends and numerical data).
- Signals: Sales, AOV (Average Order Value), and Order Count, broken down by product and region.
- Hierarchy: High-level summary > trend charts > detailed tables (top-down approach).
