# Selecting Dataset

## Introduction

A good portfolio project is not only one that showcases technical skills but also applies business knowledge with a clear objective. This means that when creating a project, we must think like a data analyst working for a company. A single project must demonstrate knowledge of the industry, a structured way of thinking, professionalism and communication skills.

The main aim of creating a good portfolio project is not actually to secure an interview invitation, but to perform well during the interview itself. As well as through real-world work experience, we can also gain this by working on portfolio projects that indirectly teach us how to convey data through storytelling.

The first step before creating a portfolio project is to determine the industry you want to enter, so that you become more familiar with the business challenges faced in that sector. After that, you can begin designing your portfolio project.

When designing it, you can use a framework known as the READY Framework.

## Project Portfolio Framework

R – Representative data
This means working with data sourced from real-world business contexts, including its irregularities and business metrics.

E – Executive-driven questions
This means having a clear objective in answering questions relevant to the company.

A – Analytical frameworks
This means having a structured framework for each stage of the work, from data cleaning, exploratory analysis, surfacing insights and creating visualisations.

D – Data best practices
This means following guidelines on the use of technical skills in line with industry standards.

Y – Your insights, your impact
This involves presenting compelling findings and demonstrating the ability to communicate these findings in a manner that is acceptable to various stakeholders.

## Process Selecting Data

**Step 1**: Find Business-Relevant Data
In line with the ‘R’ principle, which stands for ‘Representative data’ this means seeking out data that is relevant to business needs; the more relevant the data is to business and industry requirements, the easier it is to uncover the insights required for the company’s needs.

Here are some points to bear in mind:
1. Data volume: there must be at least 50,000 rows of data. This is because data analysts typically work with tens of thousands of data rows.
2. The data must have metrics and dimensions. Metrics are quantitative values that must be relevant to the target industry. Dimensions are qualitative values that provide context for the metrics (categorisation of metrics).

In this project, the dataset has already been prepared, so we can use it straight away.

**Step 2**: Defining Scope
Based on the ‘E’ principle, “Executive-driven question”, so to avoid analysis that goes round in circles without direction due to a lack of clarity regarding what the analysis is intended to achieve, the scope must be defined.

A project portfolio can be created based on questions posed by executives (for example, from managers in the finance, marketing or product departments); this allows for in-depth analysis whilst ensuring the scope remains broad enough to remain useful across various industries.

The objective of this project is *to understand sales performance during the COVID-19 pandemic, from 2019 to 2021. The results of this analysis are used to evaluate the performance of each team, enabling strategic decisions to be made to improve the company’s overall performance*.

**Step 3**: Connecting the Technical Tools 
In line with principle D "Data best practice" the tools used in this project are each designed to fulfil specific functions, ensuring a seamless working environment.
The tools used in this project are:
- Excel: for loading and cleaning data.
- Obsidian: for writing and documenting the project workflow.
- Power BI: for conducting in-depth analysis and creating dashboards.
- Draw.Io: for creating additional diagrams to complement the project.
